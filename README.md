# Workout Tracker

A local-first workout tracking web app. No cloud, no login — everything is
stored in a SQLite file on your own machine.

- **Exercise Library** — ~75 pre-seeded exercises tagged by muscle group and
  category, plus your own custom exercises.
- **Workout Logging** — start a workout, add exercises, log sets. New sets
  auto-prefill with what you logged last time you did that exercise.
- **Templates** — save any workout as a named template ("Push Day A") and
  reload it with one tap next time.
- **History & Progress** — past sessions with full set detail, plus a
  weight/volume trend chart per exercise.
- **Routine Guidance** — tell it your goal, experience level, and days/week,
  and it generates a rules-based weekly split (full body / upper-lower / PPL)
  from your exercise library, which you can edit and save.
- **Muscle Coverage** — a front/back body map shaded by how much volume
  you've hit per muscle group over the last 7 or 30 days, with a percentage
  breakdown legend.

## Requirements

Node.js 18+.

## Run it

```
npm install
npm start
```

Then open **http://localhost:3001** in your browser (phone or desktop — the
UI is mobile-friendly, so it works fine from your gym browser too).

`npm start` builds the React app and starts the single Express server that
serves both the UI and the API on one port. Data lives in
`data/workout-tracker.db` (created automatically on first run) and persists
between runs.

### Development

For hot-reloading while editing the UI:

```
npm run dev
```

This runs the Vite dev server (http://localhost:5173) alongside the API
server (http://localhost:3001), with API requests proxied automatically.

## Data model

SQLite (`better-sqlite3`), schema defined in `server/db.js`:

- `muscle_groups` — the ~12 tracked muscle groups, tagged front/back/both for
  the coverage body map.
- `exercises` / `exercise_muscles` — the library, many-to-many to muscle
  groups with a primary/secondary role.
- `workouts` / `workout_exercises` / `sets` — a logged session, the exercises
  performed in it, and each set's reps/weight.
- `templates` / `template_exercises` — reusable named workouts.
- `routines` / `routine_days` — a weekly plan mapping days to templates,
  generated by the rules-based engine in `server/routineEngine.js` and
  editable afterwards.

## Project structure

```
server/            Express API + SQLite (all data lives in data/)
  db.js              schema + seeding
  seedExercises.js   the ~75 built-in exercises
  routineEngine.js   rules-based weekly split generator
  routes/            REST endpoints per resource
src/                React app (Vite)
  components/         one component per tab/feature
  lib/                API client, shared constants, body-map geometry
```

## Notes on the routine generator

There's no ML here — it's a lookup table of splits keyed by days/week (1-2:
full body, 3: full body A/B/C, 4: upper/lower, 5: push/pull/legs + upper/
lower, 6: PPL x2), filtered by your goal (sets/reps scheme) and experience
level (exercises per day), then populated from whichever exercises are in
your library at generation time — including any custom ones you've added.
